# VisionQC: Automated Manufacturing Defect Inspection & MLOps Platform

VisionQC is an end-to-end Machine Learning Operations platform designed to automate the visual quality inspection of cast pump impellers using computer vision (PyTorch), FastAPI, Next.js, and reproducible MLOps infrastructure (DVC, MLflow, Airflow, Prometheus, Grafana).
